📦 How to package your game

  1. Put all game files in one folder. The main page must be named index.html.
  2. Add an optional thumbnail.png (or .jpg/.webp, 512×320 works best).
  3. Right-click the folder → Compress to ZIP (Windows) and upload it here.
  4. Your game is served inside a sandboxed iframe — keep all assets local, no external calls (they are blocked by the sandbox).
